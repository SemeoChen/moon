# 妮邦廚房 Ｘ 歐伯芒果 產品訂購系統

本專案依據 `moon.md` 與 `芒果恰克.txt` 需求規格設計實作，採用 **Next.js 14、React、TypeScript、Tailwind CSS** 打造，支援 PC 與手機響應式瀏覽、Vercel 部署與 Google Sheet（相容 `賣貨便_訂單匯入.xlsm`）自動寫入及 Email 確認信通知。

---

## 🌟 系統功能重點

1. **商品頁籤分類與主打商品設定**：
   * **芒果類**：
     * **芒果恰克（目前預設主打商品）**：完整呈現 `芒果恰克.txt` 介紹、私房冷凍吃法、實拍相片畫廊（`choker/*.JPG`）與限時優惠價 **$250 / 盒**（原價 $280）。
     * **芒果乾**：本年度已銷售完畢。
     * **新鮮芒果**：本年度已銷售完畢。
   * **蛋糕類（建置中）**：包含裱花蛋糕、翻糖蛋糕、戚風蛋糕、巴斯克乳酪蛋糕。
   * **餅乾類（建置中）**：手工烘焙餅乾系列。
   * **管理者設定主打商品**：可透過導覽列「主打設定」切換目前主打商品（預設為芒果恰克）。

2. **階梯式滿額運費計算（7-11 冷凍交貨便）**：
   * 溫層固定為 **「冷凍」**。
   * 未滿千元（1~3 盒）：運費 **$120**
   * 滿 $1,000（4~7 盒）：運費 **$100**
   * 滿 $2,000（8~11 盒）：運費 **$80**
   * 滿 $3,000（12 盒以上）：**免運費 ($0)**

3. **全國 7-11 門市三級選單與自動填入**：
   * 內建台灣全國 7-11 門市名稱與 6 碼店號資料庫 ([src/data/sevenElevenStores.json](file:///d:/PROJECTS/moon/src/data/sevenElevenStores.json))。
   * 買家選取「縣市 → 行政區 → 店名」後，網頁自動填入 **取件門市(代碼)** 與 **取件門市(中文店名)**。

4. **相容 `賣貨便_訂單匯入.xlsm` 之 Google Sheet 寫入與 Email 確認信**：
   * 表單欄位：收件人姓名、收件人手機、取件門市(代碼)、溫層(固定冷凍)、商品、訂單金額、運費金額、買家下訂日期、商品備註、寄件人EMAIL、希望送達日期。
   * 買家填寫之 **希望送達門市(中文)、送達日期、訂購盒數** 自動寫入 Google Sheet 的「商品備註」欄位。
   * 通過 **4 碼圖形驗證碼** 後送出訂單並顯示完成訂單彈窗；若有填寫 Email 自動發送確認信給客人。
